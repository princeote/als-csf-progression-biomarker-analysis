# ALS CSF Progression Biomarker Analysis

## Overview

This repository contains supplementary materials for an exploratory study evaluating cerebrospinal fluid (CSF) proteomic biomarkers for classifying fast versus slow ALS progression.

The study compares literature-guided biomarker panels with duration-free clinical covariates and nested data-driven feature selection using repeated stratified cross-validation.

## Primary Analysis

The primary analysis evaluates a fixed 10-20 protein literature-guided CSF biomarker panel.

## Secondary Analysis

The secondary analysis evaluates a final 5- 10 protein mechanism panel.

## Repository Structure

This repository will contain:

- documentation
- figures
- processed results
- supplementary tables

Analysis code will be added after manuscript preparation and collaborator review.
