# Literature Review Documentation

The documents in this directory summarize the evidence review performed during development of the literature-guided protein panels evaluated in this study.

These reviews were used to assess:

- Human ALS CSF evidence
- Evidence for progression-rate associations
- Biological mechanisms
- Cross-disease support
- Assay detectability
- Candidate panel refinement

The reviews are presented in approximate chronological order and document the reasoning used to develop the literature-guided protein panels evaluated in the manuscript.
